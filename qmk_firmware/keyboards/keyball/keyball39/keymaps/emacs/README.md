# キーマップ メモ

## トラックボール操作

Auto Mouseは無効。ボール操作ではレイヤーを自動切替しない。
クリックコンボ、Enter長押しのNumFn、記号レイヤーの縦スクロール、
Emacsレイヤーの横スクロールは従来どおり使用できる。

右トラックボール1個の構成では、スクロール開始時にレイヤー側で方向を
設定し直すため、EEPROMの初期化は不要。
起動直後のOLEDの方向表示は保存済み設定によって変わる場合がある。
2ボール構成や設定保存キーの追加時は、[EEPROM互換性の注意点](../../../../../../docs/change/keyball39-emacs-ux-improvements.md#eeprom互換性)を確認する。
